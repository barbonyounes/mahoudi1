# خطة مساحة الأستاذ لتحرير المحتوى

## الهدف
إضافة مساحة آمنة للأستاذ تتيح تخصيص نسخته من المنهاج والحصص بالكامل، مع بقاء الحصص الأصلية مرجعاً جاهزاً لا يتضرر.

## ما سيُبنى

### 1. حساب الأستاذ والحفظ
- تسجيل دخول للأستاذ قبل فتح أدوات التحرير.
- حفظ كل التعديلات والوثائق في Lovable Cloud لتظهر على أجهزة الأستاذ المختلفة.
- كل أستاذ يرى ويعدّل محتواه فقط، بينما تبقى الحصص الأصلية متاحة للعرض والنسخ.
- حفظ تلقائي واضح مع حالات: جارٍ الحفظ، تم الحفظ، وتعذّر الحفظ.

### 2. مكتبة المنهاج القابلة للتنظيم
- شاشة «مساحة الأستاذ» تعرض السنتين الثالثة والرابعة ومقاطع كل سنة.
- إنشاء مقطع، تعديل اسمه وميدانه، حذفه، وتحريكه للأعلى أو الأسفل.
- إنشاء مورد داخل المقطع، تعديله، حذفه، وإعادة ترتيبه.
- إنشاء حصة فارغة أو نسخ حصة جاهزة، ثم تغيير مكانها بين الموارد والمقاطع.
- حذف الحصة مع تأكيد صريح، وإمكانية استرجاع النسخة الأصلية للحصص الجاهزة.

### 3. محرر الحصة الكامل
- تخصيص الاسم، المستوى، الوحدة، الكفاءة، المدة الإجمالية، والمصطلحات.
- إضافة المحطات وحذفها ونسخها وإعادة ترتيبها.
- تعديل كل محطة: العنوان، المرحلة، الوقت، ملاحظة الأستاذ، النموذج البصري، والنقاط الأساسية.
- إضافة عناصر المحتوى وتعديلها وحذفها وترتيبها.
- دعم العناصر الأساسية التي يحتاجها الأستاذ مباشرة: نص، نقاط، سؤال واختيارات، سؤال مفتوح، تعليمة، تحليل، حوصلة، أثر كتابي، إدماج، مقارنة، وجدول.
- محرر مرن للأنواع التفاعلية المتقدمة الموجودة حالياً، حتى لا تضيع أي خاصية في الحصص الأصلية.

### 4. الوثائق والوسائط
- إضافة فيديو أو تسجيل صوتي أو محاكاة عبر رابط موثوق.
- رفع صورة أو فيديو أو صوت أو ملف PDF من جهاز الأستاذ.
- تعديل عنوان الوثيقة، مصدرها، وصفها، تعليمة استغلالها، ومدتها.
- معاينة الوثيقة، استبدالها، أو حذفها قبل حفظ الحصة.
- ملفات خاصة بكل أستاذ مع قيود للحجم والنوع.

### 5. المعاينة والنشر داخل المنصة
- معاينة الحصة أثناء التحرير بنفس عارض القسم الحالي.
- حفظ مسودة دون إظهارها في قائمة العرض.
- زر «جاهزة للعرض» يجعل النسخة المخصصة هي التي تفتح من مستوى الأستاذ.
- الحصص والمقاطع المخصصة تُدمج مع المحتوى الأصلي دون المساس بسنوات 1 و2.

## التنفيذ التقني
- جداول محمية لنسخ المناهج والحصص المخصصة، مع سياسات وصول مرتبطة بحساب الأستاذ.
- تخزين بنية الحصة كاملة بصيغة مرنة مع التحقق منها قبل الحفظ، وفهارس للترتيب والحالة.
- مساحة ملفات خاصة للوثائق المرفوعة، وسياسات تمنع وصول أستاذ إلى ملفات أستاذ آخر.
- دوال خادم محمية للنسخ، الحفظ، الحذف، النقل، وتحديث الترتيب.
- مسارات مستقلة لتسجيل الدخول، مكتبة الأستاذ، ومحرر الحصة، مع بيانات وصفية خاصة بكل صفحة.
- تعديل صفحات المستوى والحصة لتقرأ نسخة الأستاذ المنشورة عند وجودها، وإلا تستخدم الأصل.

## التحقق
- إنشاء حساب أستاذ ثم نسخ حصة أصلية وتعديل اسمها وحوصلتها.
- إضافة محطة ووثيقة مرفوعة، إعادة ترتيب المحطات، ثم حفظ ومعاينة الحصة.
- نقل الحصة إلى مورد آخر، وإنشاء/حذف مقطع ومورد مع تأكيدات الحذف.
- التأكد من بقاء الحصص الأصلية ومنع أي حساب من رؤية تعديلات حساب آخر.
- اختبار الهاتف وشاشة الحاسوب، واتجاه العربية، وحالات التحميل والخطأ والحفظ.
